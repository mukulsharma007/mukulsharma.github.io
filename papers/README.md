# papers/

Put your PDFs here, then point to them from `content.js`.
Until then those links show as "coming soon" (their value is `"#"`).

Suggested file names:

| File | Set this in content.js |
|---|---|
| `master-thesis.pdf` | `thesis.links.pdf: "papers/master-thesis.pdf"` |
| `bachelor-thesis.pdf` | `bachelor.links.pdf: "papers/bachelor-thesis.pdf"` |
| `seminar-two-factor-authentication.pdf` | `pdf` of the first entry in `papers` |
| `seminar-llm-based-agents.pdf` | `pdf` of the second entry in `papers` |
| `seminar-zero-shot-cell-embeddings.pdf` | `pdf` of the third entry in `papers` |
| `seminar-age-of-information.pdf` | `pdf` of the fourth entry in `papers` |
| `college-canteen-app.pdf` | `pdf` of the College canteen app in `projects` |

File names are case-sensitive on GitHub Pages: `Master-Thesis.pdf` and `master-thesis.pdf` are different files.

Before uploading, check that you're allowed to publish each document
(university rules, supervisor approval, any confidential data from IFW or clients).
If the thesis is in the university repository, linking there is often the better option.

Keep each PDF under 100 MB (GitHub's limit per file).
